Buku Tamu Online (Firebase)

Aktifkan agar ucapan & RSVP tamu langsung tampil di undangan untuk semua pengunjung — tanpa lewat WhatsApp. Caranya: buat project gratis di console.firebase.google.com → menu Build → Realtime Database → Create database → lalu Project settings → Your apps (Web) untuk menyalin konfigurasi di bawah. Terakhir, tempel aturan keamanan di tab Rules database tersebut. Kosongkan bila tidak dipakai — tombol WhatsApp di atas tetap jadi jalan kirim ucapan.
